ЧТО ДОБАВЛЕНО
- 4 подвижные страницы внутри раздела «Горизонталь»:
  1 СТОЛБ (A) → 2 СТОЛБ (B) → 3 СТОЛБ (C) → 3 СТОЛБА (A+B+C)
- Переключение кнопками и свайпом по панели вкладок.
- Сама таблица двигается горизонтально пальцем по всем временам.
- Даты остаются слева, времена идут по колонкам.
- На странице «3 СТОЛБА» в одной ячейке показываются A+B+C, каждая цифра со своим цветом.
- Выбор 7/14/30/60 дней и лимит строк продолжают работать через текущий app.js.
- Активные цифры 0–9 продолжают работать.

ЦВЕТА — ПОЛНАЯ ЗАЛИВКА ЯЧЕЙКИ
СИНИЙ — повтор на вторые сутки: то же число, то же время, предыдущая дата.
ЗЕЛЁНЫЙ — повтор по вертикали вправо: на предыдущей дате то же число находится в соседнем времени справа.
ОРАНЖЕВЫЙ — повтор по вертикали влево: на предыдущей дате то же число находится в соседнем времени слева.
СВЕТЛО-ГОЛУБОЙ — повтор на третьи сутки: то же число, то же время, дата двумя сутками раньше.

Если для одной клетки одновременно подходит несколько правил, используется один цвет по приоритету:
синий → зелёный → оранжевый → светло-голубой.
